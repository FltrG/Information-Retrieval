## Источник данных

Для эксперимента использовался набор данных **WikiQA** — коллекция вопросов и предложений-кандидатов, основанная на материалах Wikipedia.

Данные загружались с помощью библиотеки `kagglehub`.

## Собственный вывод

В ходе лабораторной работы были реализованы и сравнены методы ранжирования Random, Overlap, TF-IDF и BM25. Также был реализован дополнительный гибридный метод Reciprocal Rank Fusion (RRF), объединяющий результаты TF-IDF и BM25.

По результатам эксперимента лучший показатель NDCG@10 среди рассмотренных методов показал Overlap — 0.7144. Среди основных методов ранжирования лучший результат показал BM25 variant 8 — 0.6826. Гибридный метод RRF достиг значения 0.6842, немного превзойдя TF-IDF и BM25 variant.

Эксперимент показал, что объединение двух методов ранжирования может немного улучшить качество относительно каждого из них по отдельности. При этом простой лексический Overlap также показал высокий результат на данном наборе данных.
